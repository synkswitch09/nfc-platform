## Confirmado y pendiente de reproducción
AusPost MOCK-only, ausencia refunds, controles shipping de sólo lectura, comportamiento Home, falta parámetro tercera variación y transporte de stock en releases se confirman leyendo código. Carreras de stock/colas, permisos de media y round-trip release requieren reproducción integrada; no se ejecutaron ataques ni operaciones reales.

## Correcciones de hipótesis durante inspección
- REC-009, inicialmente pendiente: confirmado que media no aplica política de privacidad del perfil.
- REC-002: matización: EXISTE CHECK SQL inventory >= reservedInventory >= 0. No afirmar ausencia de constraint ni que cualquier ajuste produzca negativos. El constraint no evita liberar dos veces stock de otra reserva ni pérdida de actualización válida.
- Tercera variante Etsy sí está soportada y property IDs 513/514/516 son correctos. El gap es negociación de API, no un límite de dos variaciones.
- No atribuir de nuevo warning React key de capturas antiguas: renderer actual tiene keys. Persiste estabilidad deficiente por índice, no reproducción del warning original.
