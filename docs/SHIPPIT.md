# Shippit parcel labels

The admin order page offers Shippit when an order is `READY_TO_SHIP`. The seller enters the packed weight and outer dimensions of each box, chooses Standard or Express, and creates one Shippit order per physical box. This avoids Shippit's default behaviour of merging multiple parcel attributes into one carton. Each box may incur a separate carrier and platform charge. The checkout shipping price is still the configured store rate, not a live Shippit quote.

Set `SHIPPIT_STAGING_API_SECRET` as a secret in staging and `SHIPPIT_PRODUCTION_API_SECRET` as a separate secret in production. Staging calls `https://app.staging.shippit.com/api/3`, and production calls `https://app.shippit.com/api/3`; development refuses remote calls. Never use a live API secret in staging. Shippit accounts are tied to a dispatch location: confirm that the default shipping origin of both stores matches the Shippit location and that Australia Post / MyPost Business is enabled on that account. API credentials are server-only.

After creating a box, use **Get label** when Shippit allocation finishes. The official PDF is copied to private app storage and can be downloaded from the order page. Then **Book carrier** explicitly books that box. Only after all boxes have been booked should the seller mark the order `SHIPPED`; the app sends one existing order notification containing all tracking references. Label generation does not send a second email. Shippit may have its own notifications, which should be disabled in its merchant settings if the app's email should be the only message.

If creating or booking times out, the app intentionally blocks automatic retries: the remote operation may have succeeded. Find the box by its `retailer_invoice` (`order number` plus first eight characters of the parcel request ID) or Shippit tracking in the Shippit dashboard. Reconcile with support/operations before creating another box. The initial version supports Australian domestic labels only. The label is not available immediately on every order; a 422 from Shippit asks the seller to refresh later.
